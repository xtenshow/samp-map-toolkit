# Contributing

Issues and pull requests are welcome.

When filing an issue, include:
- Operating system and version.
- The tool/tab and exact steps that lead to the problem.
- The full error message, log, or a screenshot.
- A small reproducible sample if possible.

Please don't upload private maps, server assets, or third-party resources unless you have permission to share them. Back up original SA-MP map tiles before testing exports.

For application source, keep the Windows and Android implementations in their existing folders under `src/`. Avoid committing generated build output, APKs, EXEs, or local cache folders.
