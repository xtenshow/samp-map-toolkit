# راهنمای ساخت و استفاده

## نسخهٔ ویندوز

به Python نسخهٔ 3.10 یا جدیدتر نیاز دارید. از ریشهٔ ریپو اجرا کنید:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-windows.txt
python src/windows/Radar_Tool_v8_DPI_Responsive.py
```

برای ساخت فایل اجرایی مستقل، از تب **Actions** ورک‌فلو **Build Windows EXE** را اجرا کنید. پس از موفقیت، آرتیفکت `RadarTool-Windows-EXE` را از همان اجرای ورک‌فلو دانلود و استخراج کنید. آرتیفکت‌ها پس از ۳۰ روز منقضی می‌شوند.

## نسخهٔ اندروید

سورس Kivy/KivyMD در پوشهٔ `src/android/` قرار دارد. از تب **Actions** ورک‌فلو **Build Android APK** را اجرا کنید و بعد از بیلد موفق، آرتیفکت `RadarTool-Android-APK` را دانلود کنید.

برای ساخت محلی در محیط لینوکس سازگار:

```bash
cd src/android
python -m pip install buildozer==1.5.0 Cython==0.29.36
buildozer android debug
```

## روند پیشنهادی ادیت مپ

1. از فایل‌های اصلی رادار بکاپ بگیرید.
2. بررسی کنید ۱۴۴ فایل با نام‌های `radar00.png` تا `radar143.png` را دارید.
3. اندازهٔ هر تایل را قبل از Merge یا Split چک کنید.
4. مپ را به یک تصویر واحد تبدیل کنید و تغییرات کلی را انجام دهید.
5. خروجی را دوباره به ۱۴۴ تایل تقسیم کنید و فقط در صورت نیاز از Flip Vertical استفاده کنید.
6. خروجی را ابتدا روی یک کپی از بازی یا ریسورس تست کنید، نه روی مپ زندهٔ سرور.

## نکته‌ها

- نسخهٔ ویندوز برای کار دسکتاپ طراحی شده است.
- نسخهٔ اندروید هنوز آزمایشی است؛ انتخاب پوشه، خواندن فایل‌ها و ذخیرهٔ خروجی را روی گوشی خودتان تست کنید.
- موفقیت CI فقط نشان می‌دهد فرآیند ساخت تمام شده است، نه اینکه همهٔ قابلیت‌ها روی گوشی واقعی تست شده باشند.
