# Changelog

## Initial public repository

- Organized platform sources under `src/windows/` and `src/android/`.
- Added a polished project landing page in English and a Persian guide.
- Added a 144-tile workflow illustration and a custom SVG banner.
- Added GitHub Actions workflows to package a Windows executable and build an Android debug APK.
- Included the Android RGB replacement-color picker and the Android Storage Access Framework adapter.
- Kept generated binaries out of Git history; downloadable builds are published as workflow artifacts.

This repository is an initial organized release. The Android port remains experimental until its file access and image export flows have been tested on devices.
